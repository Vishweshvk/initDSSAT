Method and reproducibility

Evaluation is recomputed each time with python -m cli.main evaluate --crop wheat. The saved final all-data model does not generate these benchmark predictions. Preprocessors are fit only on each fold’s training experiments. The separate train-residual command fits the deployable residual model on all dataset rows.
