Method and reproducibility

Evaluation is recomputed each time with python -m cli.main evaluate --crop all. The saved final all-data model does not generate these benchmark predictions. Preprocessors are fit only on each fold’s training regions. The separate train-residual command fits the residual model on all eligible dataset rows; serving still checks the crop-region approval list.
