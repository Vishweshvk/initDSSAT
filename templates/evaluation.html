Method and reproducibility

Evaluation is recomputed each time with python -m cli.main evaluate --crop all. Saved final all-data models do not generate these benchmark predictions. Preprocessors are fit only on each fold’s training groups. The separate train-residual command fits all three residual models on all eligible dataset rows; result pages mark each output according to crop-region support.
