Multi-crop DSSAT–ML project handoff

This package includes the updated source, docs, tests, compact processed dataset, manifests, final model files, benchmark predictions/metrics/metadata, and the project brief/roadmap under HANDOFF/.

Not included: the Python virtual environment, `.env` secrets/local paths, Python/test caches, `data/runs/` generated DSSAT run archives, model backups, or the installed DSSAT program/data library. See README.md and docs/dssat_setup.md for Windows setup. The demo walkthrough is `demo.ps1`.

Quick setup in PowerShell from the extracted project directory:
  python -m venv .venv
  .venv\Scripts\Activate.ps1
  python -m pip install -r requirements.txt
  Copy-Item .env.example .env
  # Edit .env if DSSAT is not at C:\DSSAT48
  python -m cli.main doctor
  .\demo.ps1

Current paired data contain 640 experiment-treatment records across 17 reviewed crop-yield definitions. The saved five-fold grouped evaluation uses 93 experiments and 62 validation groups; pooled MAE is 522.09 kg/ha for DSSAT-only, 1,307.78 kg/ha for ML-only, and 599.05 kg/ha for the hybrid. Hybrid does not beat DSSAT-only on pooled MAE, and only separately approved crop-regions can use it. This is retrospective evaluation with full-season weather, not sowing-time forecasting or independent farm-field validation. See FINAL_CHECK.md and data/evaluation/ for current metrics and the initial historical verification.

Scenario CSV schema version 3 preserves requested/applied inputs and output provenance. It fingerprints archived DSSAT inputs and execution controls, the DSSAT executable, and the residual model when used. Full run files remain in `data/runs/<run-id>/`; these local run archives and processed benchmark artifacts are excluded from Git.
